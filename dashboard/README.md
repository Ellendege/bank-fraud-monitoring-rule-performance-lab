# Dashboard Folder

This folder contains assets and notes related to the Power BI dashboard for the **Bank Fraud Monitoring & Rule Performance Lab** project.

## Dashboard Overview
The dashboard was built in Power BI to simulate how a bank fraud analytics team could monitor fraud exposure, assess rule effectiveness, track workload, and support management decision-making.

## Pages Included
1. **Executive Overview**
   - headline fraud KPIs
   - fraud loss by channel
   - rule snapshot
   - operational snapshot

2. **Fraud Trends**
   - reviewed cases over time
   - confirmed fraud over transaction dates
   - fraud trend by channel
   - daily confirmed loss trend
   - false positive trend

3. **Rule Performance**
   - alert volume by rule
   - confirmed fraud by rule
   - conversion rate by rule
   - false positive rate by rule
   - confirmed fraud loss by rule
   - rule performance summary table

4. **Workload and Operations**
   - cases handled by investigator
   - confirmed fraud by investigator
   - alert burden by queue
   - alert priority mix by queue
   - average turnaround time
   - operational summary table

5. **Customer / Segment Risk View**
   - reviewed cases by customer segment
   - confirmed fraud by customer segment
   - confirmed fraud loss by customer segment
   - reviewed cases by region
   - confirmed fraud loss by region
   - segment summary table

## Dashboard Purpose
The dashboard was designed to show that fraud analytics is not only about identifying suspicious activity. It is also about translating fraud data into:
- financial impact visibility
- rule quality insight
- operational burden reporting
- segment and regional concentration views
- management decision support
