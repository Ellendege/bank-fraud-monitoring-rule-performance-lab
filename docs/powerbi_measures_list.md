# Power BI Measures List

## Purpose
This file lists the core measures likely needed to build the fraud dashboard in Power BI.

## Core Fraud Measures
- Total Cases Reviewed
- Confirmed Fraud Cases
- False Positive Cases
- Total Confirmed Loss
- Total Recovery Amount
- Net Loss
- Confirmed Fraud Rate %
- False Positive Rate %

## Rule Performance Measures
- Total Alerts
- Confirmed Fraud Cases by Rule
- False Positive Cases by Rule
- Alert-to-Fraud Conversion Rate %
- False Positive Rate by Rule %
- Confirmed Fraud Loss by Rule
- Net Loss by Rule

## Trend Measures
- Reviewed Cases by Date
- Confirmed Fraud Cases by Transaction Date
- Daily Confirmed Loss
- Daily False Positive Cases

## Workload Measures
- Cases Handled by Investigator
- Confirmed Fraud Cases by Investigator
- Alert Count by Queue
- High Priority Alert Count
- Average Turnaround Time
- Total Loss Handled by Investigator

## Segment / Region Measures
- Reviewed Cases by Customer Segment
- Confirmed Fraud Cases by Customer Segment
- Confirmed Fraud Loss by Customer Segment
- Reviewed Cases by Region
- Confirmed Fraud Loss by Region
- Net Loss by Region

## Build Note
Some of these measures can be created directly in Power BI, while others may also be supported by pre-aggregated SQL outputs depending on the final dashboard build approach.
