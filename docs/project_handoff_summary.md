# Project Handoff Summary

## Project Name
Bank Fraud Monitoring & Rule Performance Lab

## Project Purpose
This project was built to simulate how a bank fraud analytics team monitors fraud activity, evaluates rule effectiveness, tracks operational burden, and supports risk-based management decision-making.

## What Has Been Built

### 1. Folder Structure
Created the full project folder structure, including:
- data/
- sql/
- excel/
- dashboard/
- reports/
- docs/

### 2. Core Documentation
Created:
- README.md
- dataset_dictionary.md
- project_scope.md
- interview_notes.md
- project_progress_summary.md
- dashboard_plan.md
- powerbi_build_checklist.md
- powerbi_measures_list.md

### 3. Data Layer
Created raw and cleaned CSV files for:
- transactions
- alerts
- rules
- cases
- customers

Added sample data to the raw files and copied them into cleaned working versions.

### 4. SQL Data Checks
Created SQL scripts for:
- row counts
- null checks
- key link checks

### 5. KPI Layer
Created SQL scripts for:
- core fraud KPIs
- KPI breakdowns by channel
- customer segment
- region

### 6. Fraud Trend Layer
Created SQL trend queries for:
- case open date
- transaction date
- channel trend over time

### 7. Rule Performance Layer
Created SQL queries for:
- alert volume by rule
- confirmed fraud by rule
- conversion rate by rule
- false positive rate by rule
- rule loss impact

### 8. Workload Layer
Created SQL queries for:
- investigator case volume
- queue burden
- case turnaround time

### 9. Dashboard Planning Layer
Documented:
- dashboard purpose
- target users
- page structure
- page layouts
- SQL-to-page mapping
- visual specifications
- chart titles
- build checklist
- measure list

## Current State of the Project
The project is now structured, documented, and analysis-ready. The SQL logic and dashboard planning are in place, but the dashboard has not yet been built in Power BI.
